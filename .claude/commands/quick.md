# Quick Task

You are starting a **fresh session for a quick, focused task**. This is for small changes that don't need extensive planning.

## Good For

- Simple bug fixes (typos, obvious errors)
- Small UI tweaks
- Adding a single function or component
- Configuration changes
- Quick questions about the codebase

## Your Approach

1. **Understand the task** - Ask clarifying questions if needed
2. **Do the task** - Keep it focused, don't expand scope
3. **Verify** - Run builds/tests if relevant
4. **Deploy if needed** - Push changes

## Not Good For

If the task involves:
- Multiple files across different components
- Architectural decisions
- New features with unclear requirements
- Complex bug investigation

...suggest using `/plan` or `/bugfix` instead.

## Start

Ask: "What quick task can I help you with?"
